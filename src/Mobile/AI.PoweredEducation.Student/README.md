# AI-Powered Education Student

Flutter mobile application for students.

## Scope

- Join a learning game with a game code and student name.
- Store the student session token securely.
- Navigate to the game lobby after a successful join.
- Keep gameplay, QR scanning, GPS tracking, and maps out of this initial skeleton.

## Setup

Flutter SDK is required. After installing Flutter, run:

```bash
flutter pub get
flutter create --platforms=android,ios .
```

Then start the app with:

```bash
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:5099
```
